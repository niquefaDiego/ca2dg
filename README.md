# Computer Assisted 2D Geometry

## Requirements

- Raylib: https://github.com/raysan5/raylib


## Coding convention

Use camel case for naming variables, functions, structs and macros.

Functions, structs, macros and variables in global scope start in upper case.

Struct fields and local variables start in lowercase.

Structs with the `Singleton` indicate there is a single global instance.
